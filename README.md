# Генератор номерного знака по ГОСТ'У

Онлайн-генератор российских номерных знаков по ГОСТ Р 50577. Настройка букв и цифр, экспорт в PNG 520×112 с прозрачным фоном. Бесплатно, без регистрации.

[Перейти на сайт](https://qupinator.github.io/MalCoin/gost)

## Пример
![Пример сгенерированного номерного знака](https://eblo.id/uploads/gb9w80l/к067ек_67.opt.webp)
> _По углам фон прозрачный._

## Возможности
- 3 режима: **Обычный** (12 букв ГОСТ), **Чит-мод** (все RU/EN), **Свободный** (до 6/9 символов).
- Тёмная/светлая тема, тень и её цвет, подсветка «редких» номеров.
- Экспорт PNG 520×112, копирование по клику, вставка из буфера.
- Горячие клавиши: `Ctrl+Alt+R` — случайный номер, `Ctrl+Shift+C/V` — копировать/вставить.

## Использование
Откройте [Сайт](https://qupinator.github.io/MalCoin/gost), выберите режим, настройте номер и скачайте PNG.
